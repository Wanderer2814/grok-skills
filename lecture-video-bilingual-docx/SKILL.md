# 讲座视频文字稿

用户一旦要求把**视频或录屏**转录成文字稿，就按本技能交付。读者是中文母语者。不要先问要不要英文、要不要中文、要不要时间戳、要不要插入 PPT。先判断现场语种，再套对应版式。

## 先判断语种

整理出全文之后、排版之前，把整场分成三类。分类看的是**成段发言**，不是句子里夹着的专名。

| 类型 | 怎么认 | 版式 |
|---|---|---|
| 全文中文 | 现场主要是中文。英文只是术语、案例名、法条简称、软件名，嵌在中文句子里 | **只出中文。** 不另写英文稿，不把中文再译成英文 |
| 全文英文 | 现场主要是英文。开场一句中文问好、零星中文专名，仍算全文英文 | **英文整篇在前，中文译文整篇在后。** 中文是完整翻译，不是摘要 |
| 部分英文 | 有成段的英文发言，其余是中文。例如某位嘉宾整段用英文，或中文讲座里插入连续数句英文陈述 | **只出一份按时间线排的稿。** 中文段照录。每一段英文后面紧接该段的中文译文。不要在文末再重出一整篇 |

夹在中文句子里的英文词（Skill、MCP、IEEPA、PIIE）留在原句，不拆出来另译。听不清的英文整句才标 `[unclear]`，并在后面按听得清的部分写译文；整句都听不清则只标［听不清］，不编译文。

用户当次如果明确改口（只要英文、不要译文、中文场也要英文），按当次的话做。没改口就用上表。

## 交付物

一个 `.docx`。文件名：`主题_机构_YYYY-MM-DD.docx`。

三种版式都要有：

1. 文首：标题、主办机构、日期、主持与嘉宾及职衔、视频链接、活动页链接、编辑说明。说明里写明本场判定为「全文中文 / 全文英文 / 部分英文」中的哪一种。
2. 发言人姓名单独成行、加粗。同一人的连续发言按意思分成完整段落。终稿不出现任何时间戳。
3. 讲座里出现的 PPT，以图片插在讲者开始讲这一页的那一句之前。图下用一行斜体写明是谁的第几页、这一页在讲什么。
4. 不插入发言人摄像头画面。没有共享幻灯片时，正文写明「本场未共享演示文稿」，只保留开场等候页（若画面上有）。不要用空白占位假装有幻灯片。

幻灯片插几次，跟语种走：

- **全文中文、部分英文：** 每一页只插一次，插在原文里讲到它的位置。部分英文场里，译文紧跟在英文段落后，译文下面不要把同一页再贴一张。
- **全文英文：** 英文部分插一套，中文部分在对应位置再插一套。图注各用该节的语言。

部分英文场的译文：紧接在该英文段落之后，另起一段，段首标「译文」。译文与该段对应，不摘要。中文发言段不要加「译文」。

同时遵守 `full-document-no-summary`：不得因篇幅改成摘要，不得写「因篇幅从略」，不得用「（待续）」占位。该译的英文必须全译。

## 何时不用

| 情况 | 改用 |
|---|---|
| 只有 m4a / mp3 / wav，没有画面 | `conference-paragraph-transcript` |
| 已经有文字稿，只要改格式、校对或翻译 | 按当次要求，不重跑本流程 |
| 用户明确只要摘要，或明确不要幻灯片 | 按当次更具体的话做 |

## 文字从哪里来

按这个顺序，用到能做干净全文为止：

1. **主办方公布的未编辑逐字稿**（活动页上的 unedited transcript、PDF）。以此为底本。它仍是口误识别稿，必须校正人名、机构名、法律和贸易术语、明显误听。
2. **视频字幕。** 有人工字幕用人工字幕。否则用原语言自动字幕（英文场用 `en-orig`，中文场用中文）。滚动字幕合并重叠句，同一句只留较完整的一次。
3. **都没有，再对音轨识别。** 长音频按约 5 分钟分段，避免整场一次载入。工作底稿可以留时间轴，用来对齐幻灯片；交给用户的 Word 里删掉时间戳。

不编造没说过的论点，不按题目补写。听不清：英文标 `[unclear]`，中文标［听不清］。

### 校订边界

- 用活动页、幻灯片和自我介绍核对姓名与职衔。例：PIE 写成 PIIE；把 Emergency Powers Act / AIPA 听成的说法改回 IEEPA，仅当上下文不可能是别的法律。
- 发言顺序以实际出场为准。主持人口头预告的顺序可以和后来不一致，按实讲的顺序写。
- 去掉 um、uh、嗯、啊和明显的同词重复。不把口语改成论文摘要。
- 分不清是谁，写「发言人」加编号，不要猜一个错名。
- 句子切分时不要在 `U.S.`、`Mr.`、`Dr.` 的句点处断开。先把 `U.S.` 统一成 `US` 再分段。

## 幻灯片

1. **先找主办方公布的演示文稿**（活动页的 Presentation PDF，或讲者给出的课件）。有则把该 PDF 逐页渲染成图（约 120 dpi）。这就是现场那套片子，不要再用模糊的视频截图替换同一页。
2. 没有公布稿，才从视频抽帧。检出画面切换，裁出投影区域，丢掉几乎相同的帧和纯摄像头画面。
3. **插入位置是讲者开始讲这一页的那一句之前**，不是按 PDF 页码堆在每人开头。
   - 标题页：放在报出演讲标题处。
   - 数据页、机制页：放在开始讲述该图或该组要点的句子之前。
   - 结束页：放在这段报告说完、下一位接话之前。
4. 讨论环节没有翻页，就不插。回翻已经讲过的一页，再插一次。
5. 一闪而过、口播对不上的页不硬插。休息页不插。
6. Zoom 圆桌若全程只有开场等候卡（例如 “The webcast will begin shortly”）：正文开头放一次，并写明此后没有幻灯片。全文英文场则两种语言正文开头各放一次。

图注示例：`朱玲凤，第12页。把重复工作收成一个 Skill。` 全文英文场的英文图注：`Mary E. Lovely, slide 4. Chinese value-added exports versus direct exports.`

## Word 版式

- A4。西文 Times New Roman，中文宋体，标题可用黑体。
- 发言人姓名单独成段、加粗。正文紧随其后。
- 部分英文场里，「译文」三字加粗，译文正文用宋体，不另起一套标题层级。
- 幻灯片居中，宽度约 6.1 英寸，图注 9 磅斜体。
- 文首说明写清：这是口头发言整理稿；机器转写或主办方逐字稿已校订人名和明显误听；本场语种判定；幻灯片来自公布的正式稿还是视频截图。全文英文场还要写明中文是全文译文不是摘要。

## 顺序

1. 确认是视频或录屏，而不是纯音频。记下标题、日期、机构、时长、活动页。
2. 取文字（逐字稿，否则字幕，否则分段识别）。
3. 取幻灯片（公布的 PDF，否则抽帧）。没有片子就明确写没有。
4. 标发言人，去掉时间戳，按现场语言收成整段。判定全文中文、全文英文，还是部分英文。
5. 把每一页插到原文中开始讲该页的句子之前。全文英文场先插在英文里。
6. 通读：有没有残留时间戳，有没有把两个人并进一段，有没有用摘要代替发言，幻灯片是否落在开始讲该页的地方，语种版式有没有用错。
7. 需要译文时再译。全文英文：术语表先定好，整篇译完接在英文后面，译本按同样位置再插同一套图。部分英文：只译成段的英文，译文紧跟该段，幻灯片不重复。全文中文：停在这里，不译。
8. 生成 docx 并给出下载。用几句说明场次、语种判定、幻灯片来源，以及仍不确定的姓名。

## 不要

| 不要 | 为什么 |
|---|---|
| 终稿保留 `[00:12]` 或 `(12:03)` | 用户明确不要时间戳 |
| 中文场再出一篇英文，或把中文译成英文放在前面 | 读者是中文母语者；中文录音、中文录屏只要中文 |
| 全文英文却改成逐段中英交替 | 全文英文仍是英文整篇在前、中文整篇在后 |
| 部分英文却把译文整篇挪到文末，或中英逐句交替 | 译文紧跟每一段英文，中文段保持原样 |
| 只译要点、只写会议纪要 | 要的是全文文字稿 |
| 把人像截图当成 PPT | 只插演示画面 |
| 视频转录时再问「要不要英文」 | 按语种表决定，不问 |
| 有正式 PDF 却只用低清视频截图 | 正式稿更清楚，且就是现场那套片子 |
| 按议程补写没讲的内容 | 伪造记录 |
