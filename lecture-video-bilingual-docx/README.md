# lecture-video-bilingual-docx

把讲座、网络研讨会、圆桌的**视频或录屏**做成一份 Word。读者是中文母语者。

用户只要说「把这个视频转录成文字稿」，就按现场语种交付，不必每次重复格式：

1. **全文中文：** 只出中文，不另写英文。
2. **全文英文：** 英文整篇在前，中文译文整篇在后。中文是译文，不是摘要。
3. **部分英文：** 一份按时间线排的稿。每一段英文后面紧接该段中文译文。中文段照录。
4. 终稿不带时间戳。
5. 讲座中出现的 PPT 按讲到该页的位置插入。中文场和部分英文场每页只插一次；全文英文场两种语言各插一套。
6. 不插入发言人摄像头画面。没有共享幻灯片时写明，并只保留开场等候页。

纯音频（m4a / mp3 / wav）仍用 `conference-paragraph-transcript`。
