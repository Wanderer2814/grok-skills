# conference-paragraph-transcript

会议录音的**终稿**技能。降噪和二次识别仍用 `noisy-conference-asr-recovery`，本技能不替代它。

触发：用户给出录音并要求转成文字。已有文字稿的修改、翻译不触发。

第一遍若有连续 ≥ 60 秒无法识别（无可用词、时间轴跳过、或长段幻觉空转），自动对原音频做二次识别（`noisy-conference-asr-recovery`），不先询问，也不再问能不能听原文件。只切空白段。原文件没送达时，允许访问不能把整场变出来，改为请用户裁 10–16 分钟片段。然后：

1. 区分发言人（议程对不上就用「发言人 + 编号」）。
2. 收成完整段落，终稿不带时间戳。
3. 终稿正文若是英文，整篇中文译文接在全部英文之后，不摘要。

安装：本目录作为 Grok skill（根目录有 `SKILL.md`）。
