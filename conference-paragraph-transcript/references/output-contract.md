# 终稿体例

2026-09-23 用户确认：对「中国政法大学吉林大学武汉大学司法文明协同创新中心 3」上午场的段落稿满意，并要求以后都这样。同日补充：触发是「给出录音并要求转为文字」；大片无法识别时自动启用降噪技能。

原话要点：

- 去掉时间戳。
- 每个人的话按完整段落处理。
- 英文稿处理完，再全部译成中文，整篇加在英文后面。
- 触发：给录音、让转为文字。
- 出现大片无法识别的段落，自动启用降噪 skill。

「大片」定为连续 ≥ 60 秒：没有可用词，或时间轴一次跳过这么久，或同一句幻觉空转。短于 60 秒的个别听不清不启用。不要先问要不要降噪。

## 结构

```
文首（会议名、日期、地点、主持人、发言人对照、体例说明）

第一部分  英文文字稿

【主持人：姓名（单位）】

段落。

段落。

【发言人：姓名（单位）】

段落。

第二部分  中文译文

（若第一部分是英文，才有这一部分）

【同一发言人标题】

与英文章节对应的段落。
```

发言人标题两边一致，顺序一致。英文有几段，中文就有几段。不要在中文里加回时间戳。

## 从识别句收到段落

识别结果常是重叠短句，例如同一句出现两次、后一句只多几个词。终稿只保留一句，取更完整、更通顺的那句，再和前后句连成口语段落。

保留：论点、例子、案子、数字、条文、提议、第一人称、说话顺序。

删掉：纯重复、无内容的幻觉循环（同一短语空转多遍且没有新信息）。若删完该处没有剩余信息，标 `[unclear]`，不要用议程标题填上。

一段连续发言中途被主持人打断，主持人单独成段，不要并进前一位的段落。回应环节用「姓名 回应」，不要并回主旨发言。

## 发言人

1. 议程 PDF 上的姓名、单位、题目，用来对照，不用来补写正文。
2. 自我介绍听得清，以自我介绍为准。
3. 只听到机构、听不清姓名：标题写「发言人 N（机构）」，文首说明依据。本场代奕波即属此类，标题可以写上推定姓名，但必须注明「未清晰自报，若有误改回发言人 N」。
4. 误听名不进标题，也不当正文里的自称。正文可写「录音未听清姓名，按议程为某某」。

## 英文终稿才译中文

「最后形成的转录稿件是英文的」才在文末加整篇中文。

- 英文发言 → 英文段落稿 → 文末中文。
- 中文发言 → 中文段落稿即可。
- 一场里中英夹杂：正文跟实际所说的语言走；只有整场终稿主体是英文时，才在后面加全篇中文。不要把中文句子抽出来再译一遍英文。

翻译要求：不摘要；`[unclear]` → ［听不清］；人名机构与文首对照表一致；不把没出现的法规号补进去。

## 工作底稿 vs 终稿

| | 工作底稿 | 终稿 |
|---|---|---|
| 时间戳 | 可以有，用于贴回原录音 | 禁止 |
| 重复短句 | 可以先留着 | 合并 |
| 谁来做 | 降噪技能的识别结果 | 本技能 |

用户若明确说「我要时间戳」，才把时间戳加回终稿。默认不加。
